# 股票分析

股票与加密货币分析（8 维评分、组合管理、观察名单告警、趋势扫描、传闻探测）。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/stock-analysis#v1.0.3 --skill stock-analysis
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill stock-analysis
```

## 内容

技能正文在 `skills/stock-analysis/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/stock-analysis/payload/`，不要反向同步。版本以 git tag 为准。
